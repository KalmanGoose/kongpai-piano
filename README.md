## 🎮 操作方式
- **白鍵**：鍵盤中間基準排 `A S D F G H J K L ;`
- **黑鍵**：鍵盤上方排 `W E T Y U O P`
- **即時和弦引導**：鍵盤會用黃色發光標出《空拍》的官方和弦（Cadd9、G/B、Am7、Fsus2、E -> E/G# 等）！
- **伴奏同步**：內建原曲伴奏音軌與節拍軌，支援 0.75x 慢速與 3/4 拍節拍動畫。
